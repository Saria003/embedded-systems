# 01 - LED Blinking

## Objective
Build a simple LED blinking circuit using an Arduino Uno.

## Components
- Arduino Uno
- LED
- 220Ω resistor
- Jumper wires

## Simulation
Created and tested using [Wokwi](https://wokwi.com/).

## What I learned
- Basic Arduino program structure
- Using `pinMode()` to configure GPIO pins
- Using `digitalWrite()` to control digital outputs
- Using `delay()` to control timing
